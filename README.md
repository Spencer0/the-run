# The Run

A momentum runner. You are a tech gnome who unbolted a Halvex Robotics spider-walker (wheels on every foot) and rode it out the loading door. Build speed, keep it, and use it to clear ravines, launch off ramps and thread the recall crew's spikes, drones and laser gates.

Three levels, five gates each. Every gate saves a checkpoint and offers one of three parts (top speed, acceleration, jump, air control, shield, grip, bolt magnet). The **Checkpoint** button (or `R`) rewinds you to the last gate, because losing momentum in the wrong spot can leave you stuck.

| Level | Theme |
| --- | --- |
| 1 | Tropic Thunder: jungle ruins under a lightning storm |
| 2 | Cyberspace: neon data lanes and a scanline sun |
| 3 | The Freighter: a container ship deck with open holds |

## Controls

- **Steer**: drag a finger left or right, or `A`/`D` / arrow keys
- **Jump**: tap, or `Space`. Hold for a longer arc. A second finger while steering jumps instantly.
- **Rewind to checkpoint**: the on-screen button or `R`
- **Pause**: `Esc` / `P`. **Mute**: `M`.

## Running it

The game is plain ES modules plus Three.js from a CDN, no build step. Serve the folder with any static server and open `dev.html` (a wrapper around `index.html`, regenerated by `./build-dev.sh`):

```sh
python3 -m http.server 8765
# then open http://127.0.0.1:8765/dev.html
```

`index.html` itself is written for the Claude artifact host, which wraps it in a document skeleton.

## Layout

- `index.html`: markup, CSS, import map, HUD and menus
- `src/main.js`: game loop, physics, camera, collisions, state machine
- `src/level.js`: seeded chunk-based level generator and collision queries
- `src/world.js`: builds track slabs, hazards, bolts and gates from level data
- `src/themes.js`: the three environments (sky, fog, lights, scenery, weather)
- `src/textures.js`: procedural canvas textures
- `src/mech.js`: the spider-walker and its rider, procedurally animated
- `src/post.js`: post-processing (radial speed blur, bloom, chromatic aberration, vignette, speed wobble)
- `src/audio.js`: Web Audio engine hum, wind, SFX and a small per-theme sequencer
- `src/input.js`: touch, mouse and keyboard
- `src/ui.js`: HUD, menus and the upgrade table

## Tuning notes

Physics lives at the top of `src/main.js` (`G`) and in `resetRun()` (base acceleration, top speed, jump). Gap widths, ramp angles and hazard density scale with a `tier` value in `src/level.js` that rises per section and per level.
